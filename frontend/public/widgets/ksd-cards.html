📦
Distribuição
O pacote completo
O que é: Kernel + shell + programas + gestor de pacotes, tudo empacotado e testado para funcionar junto.

Analogia: A loja que vende o carro completo (motor, volante, bancos).
📞
Shell
A "casca"
O que é: Interpreta comandos do terminal (bash, zsh). Pega o comando e pede para o kernel executar.

Analogia: O telefone que usas para falar com o gerente.
⚙️
Kernel
O "motor"
O que é: Núcleo do sistema. Conversa diretamente com o hardware (CPU, RAM, discos).

Analogia: O gerente da fábrica.
Distro→Shell→Kernel
