Ubuntu / Debian

Foco em estabilidade e facilidade de uso. Ideal para iniciantes e servidores.

sudo apt install <pacote>

Fedora / RedHat

Comum no mundo corporativo. Usa dnf como gestor de pacotes.

sudo dnf install <pacote>

Arch Linux

Rolling release, sempre atualizado. Customizável, constróis o sistema do zero.

sudo pacman -S <pacote>
