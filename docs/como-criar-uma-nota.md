# Como criar uma nota e publicar no site

## O que são as notas

As notas são apontadores de estudo que escreves enquanto estudas um módulo. São guardadas **automaticamente no teu browser** (localStorage), organizadas por módulo, e podes:

- Copiar a nota como Markdown (para colar onde quiseres)
- Publicá-la no teu repositório GitHub (ver [Como usar a funcionalidade Git Push](como-usar-git-push.md))

## Passo a passo

### 1. Abre as notas

**Mobile (telemóvel/tablet):** toca no separador **Notas** na barra de navegação inferior.

**Desktop:** as notas ficam no painel à direita. Se estiverem recolhidas, clica no botão com o lápis na tira lateral direita.

### 2. Preenche os campos

Cada nota tem três campos (editor de texto com barra de formatação):

| Campo | O que escrever |
| --- | --- |
| **O que aprendi** | Explica como se fosses ensinar a um amigo. 2–3 frases bastam. |
| **Dificuldades** | O obstáculo que encontraste — identificá-lo é o primeiro passo. |
| **Próximo passo** | Uma ação concreta para continuares (ex: fazer um desafio). |

A nota é salva automaticamente enquanto escreves — não há botão de guardar.

### 3. Publica a nota

- **Copiar Markdown** — copia a nota formatada para a área de transferência. Cola onde quiseres (ficheiro `.md`, Obsidian, Notion, GitHub…).
- **Push para o GitHub** — publica diretamente no teu repositório (ver o [guia do Git Push](como-usar-git-push.md)).

### 4. Estado da nota

- Uma nota sem nenhum campo preenchido está **vazia** e não pode ser publicada/copiada.
- As notas são por módulo: quando mudas de módulo, vês a nota desse módulo.

## Limitações

- As notas ficam guardadas **apenas no browser** onde as escreveste. Usar outro dispositivo ou limpar os dados do browser apaga-as (a menos que as tenhas publicado no GitHub).
- Para garantir, publica as notas importantes no teu repositório — assim ficam seguras na tua conta GitHub.
